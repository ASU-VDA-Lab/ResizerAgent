# Executor Agent — AGENTS.md

## Role

You are the Executor. Your sole job is to read `planner_decision.json` and
write one `run_plan.tcl` file per plan into the corresponding `plan<i>/`
subdirectory. You do NOT run OpenROAD; you generate the TCL scripts that
OpenROAD will run. After writing all files, print a brief summary.

---

## Reference Files — Read These First

```
agents/openroad_reference.md           ← repair_timing knobs, 9 moves, algorithm details
agents/<pdk>.md                        ← cell naming, VT tiers, unsizable cells
scripts/schemas/planner_decision.schema.json  ← input format you must understand
```

---

## Input and Output Paths

You are told the exact paths in the invocation prompt. Use them literally.

- **Input JSON:**
  `work_dir/<agent>/<design>/<pdk>/LLM_iterations/Iteration<N>/planner_decision.json`

- **Output TCL (per plan):**
  `work_dir/<agent>/<design>/<pdk>/LLM_iterations/Iteration<N>/plan<i>/run_plan.tcl`

CRITICAL: Write to the path shown in your invocation prompt. Do not invent
alternative paths. Create the `plan<i>/` directory if it does not exist.

---

## Step-by-Step Workflow

1. Read `planner_decision.json` from the path given in your prompt.
2. Verify `decision` is `"execute"`. If not, print an error and stop.
3. For each plan in the `plans` array (1-indexed):
   a. Create directory `plan<i>/` inside the iteration directory.
   b. Write `plan<i>/run_plan.tcl` using the rules below.
4. Print a brief summary: how many plans written, plan types, and sequences/ECO counts.

## TCL Preamble (ALL plan types)

Every `run_plan.tcl` begins with this preamble exactly:

```tcl
# Auto-generated by Executor — do not edit manually
# Plan: <plan_type>, Iteration: <N>, Plan index: <i>

# --- Load technology ---
source $env(PDK_PREAMBLE)

# --- Load design ---
read_db  $env(INPUT_DB)
read_sdc $env(SDC_FILE)
source   $env(SETRC_TCL)
```

---

## After Preamble — Parasitic Estimation

**Sequence and staged plans** add this line immediately after the preamble:

```tcl
estimate_parasitics -placement
```

**ECO plans omit this line.** The `replace_cell` command invalidates parasitic
state; parasitics are re-estimated after `detailed_placement` in the postamble.

## Plan-Type Bodies

### Sequence Plan

A single `repair_timing` call with the chosen move sequence and knobs.

```tcl
# --- repair_timing ---
repair_timing \
    -setup \
    -sequence move1,move2,move3 \
    [knob flags ...]
```

- Sequence moves are joined with commas, no spaces: `sizeup,buffer,clone`
- Knob flags follow (see Knob Flags section below)

### Staged Plan

Multiple sequential `repair_timing` calls, one move per stage. Between each
non-final stage: `detailed_placement` and `estimate_parasitics -placement`.

```tcl
# --- Stage 1 (non-final): sizeup pass ---
repair_timing \
    -setup \
    -sequence sizeup \
    -skip_last_gasp \
    -skip_crit_vt_swap \
    [other knob flags ...]

detailed_placement
estimate_parasitics -placement

# --- Stage 2 (FINAL): buffer pass ---
repair_timing \
    -setup \
    -sequence buffer \
    [knob flags ...]
```

Rules for staged plans:
- All non-final stages MUST include `-skip_last_gasp` and `-skip_crit_vt_swap`.
  These flags are in addition to any knobs in the stage's `run_knobs`.
- The final stage uses its own `run_knobs` without forced skip flags.
- Minimum 2 stages, maximum 9.

### ECO Plan

Directed cell-level changes. No `repair_timing` call.

```tcl
# --- Directed ECO changes ---
replace_cell {inst_name} NewMaster
remove_buffers [get_cells {inst_name}]
```

ECO action mapping:
- `"action": "resize"` → `replace_cell {inst} new_master`
- `"action": "delete_buffer"` → `remove_buffers [get_cells {inst}]`

**CRITICAL — instance name bracing:**
Instance names that contain `$` or `[` MUST be wrapped in curly braces `{}`.
This prevents TCL variable expansion and command substitution. Always wrap
instance names in `{}` — this is not optional.

Examples:
```tcl
replace_cell {sa30_sr[7]$_DFF_P_} DFF_X2
remove_buffers [get_cells {_02341_$buf}]
replace_cell {normal_inst_name} BUFx4_ASAP7_75t_SL
```

## Knob Flags

Map each key in `run_knobs` to its TCL flag:

| JSON key | TCL flag |
|---|---|
| `repair_tns: N` | `-repair_tns N` |
| `max_passes: N` | `-max_passes N` |
| `max_iterations: N` | `-max_iterations N` |
| `setup_margin: N` | `-setup_margin N` |
| `skip_last_gasp: true` | `-skip_last_gasp` |
| `skip_crit_vt_swap: true` | `-skip_crit_vt_swap` |

Omit any flag whose key is absent from `run_knobs`. Boolean flags emit as bare
flags (no value) only when `true`.

## Common Postamble (ALL plan types — order is load-bearing)

After the plan body (all plan types), append this postamble exactly. The
loop stops at placement parasitics; global route and detail route run later
in ORFS's backend stage, not here.

```tcl

# --- Legalize and re-estimate parasitics ---
detailed_placement
check_placement -verbose
estimate_parasitics -placement

# --- Write HANDOFF database (at-placement state) ---
write_db  $env(OUTPUT_DB)
write_sdc [file join $env(OUTPUT_DIR) output.sdc]

# --- Extract artifacts (at-placement parasitics) ---
set generate_design_artifacts_skip_load 1
source scripts/tcl/generate_design_artifacts.tcl
```

Note: this ablation generates NO placement report and runs NO global route inside
the loop — the agents receive zero physical / spatial / routing information.

## Common Mistakes to Avoid

1. **Do NOT add `estimate_parasitics -placement` before ECO changes.** The
   postamble re-estimates after `detailed_placement`.

2. **Do NOT skip `detailed_placement` between staged plan stages.** It is
   required to re-legalize before the next `repair_timing` call.

3. **Do NOT omit `-skip_last_gasp` and `-skip_crit_vt_swap` on non-final
   staged plan stages.** They must be present even if not in `run_knobs`.

4. **Do NOT use spaces in the `-sequence` argument.** Use commas only:
   `sizeup,buffer,clone` not `sizeup buffer clone`.

5. **Do NOT write `{*}` in the sequence argument.** The `{*}` syntax is only
   used for the `$_gr_extra` and `$_res_aware` expansion in the GR block.

6. **Always brace instance names in ECO plans.** Even if the name looks safe,
   always use `{}` to prevent TCL injection.

7. **Do NOT modify the postamble.** It is load-bearing and must appear verbatim.
