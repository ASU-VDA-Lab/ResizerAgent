# ============================================================
# ASAP7 Cell Library — LLM Reference Guide
# ============================================================
#
# SIZE NOTATION
# All sizes follow the pattern x<integer>[p<fraction>][suffix]:
#   "x"  prefix means "times" (drive strength multiplier)
#   "p"  means decimal point: xp5 = 0.5x, x1p5 = 1.5x, xp33 = 0.33x
#
# Ordered size ladder (weakest to strongest drive):
#   x1 < x2 < x3 < x4 < x5 < x6 < x8 < x10 < x11 < x12 < x13 < x14 < x16 < x20 < x24
#
# Larger size = stronger output drive = lower propagation delay = more area and power.
# sizeup moves to the next larger size in the same family and same VT tier.
# sizedown moves to the next smaller size.
#
# VT FLAVORS — INFORMATIONAL ONLY (VT swap is DISABLED in this flow)
#   SLVT  Super-Low-Vt  fastest switching, highest leakage
#   LVT   Low-Vt        moderate speed and leakage
#   RVT   Regular-Vt    slowest switching, lowest leakage
# All repair moves stay within the same VT tier as the existing cell.
# Do NOT suggest VT-based moves; -skip_crit_vt_swap is always active.
#
# AVAILABLE REPAIR MOVES
#   sizeup        Replace cell with next larger drive-strength variant (same family, same VT)
#   sizedown      Replace cell with next smaller drive-strength variant
#   sizeup_match  Sizeup to best match the downstream capacitive load
#   buffer        Insert a BUF on a high-capacitance or long interconnect net
#   unbuffer      Remove a redundant buffer that adds delay without driving benefit
#   clone         Duplicate a high-fanout cell; each copy drives a subset of the fanout
#   split         Split a heavily loaded net into two sub-nets, each independently driven
#   swap          Swap to a logically equivalent cell in a different family
#
# CELL FUNCTION REFERENCE
#   INV           Inverter:              Y = !A
#   BUF           Buffer:                Y = A   (used for drive strength or signal integrity)
#   NAND2/3/4/5   NAND gate
#   NOR2/3/4/5    NOR gate
#   AND2/3/4/5    AND gate
#   OR2/3/4/5     OR gate
#   XOR2          Exclusive-OR:          Y = A ^ B
#   XNOR2         Exclusive-NOR:         Y = !(A ^ B)
#   AOI21         AND-OR-INV (2-1):      Y = !((A1 & A2) | B)
#   AOI22         AND-OR-INV (2-2):      Y = !((A1 & A2) | (B1 & B2))
#   AOI31         AND-OR-INV (3-1):      Y = !((A1 & A2 & A3) | B)
#   OAI21         OR-AND-INV (2-1):      Y = !((A1 | A2) & B)
#   OAI22         OR-AND-INV (2-2):      Y = !((A1 | A2) & (B1 | B2))
#   OAI31         OR-AND-INV (3-1):      Y = !((A1 | A2 | A3) & B)
#   AO21          AND-OR (2-1):          Y = (A1 & A2) | B
#   AO22          AND-OR (2-2):          Y = (A1 & A2) | (B1 & B2)
#   OA21          OR-AND (2-1):          Y = (A1 | A2) & B
#   MAJ           Majority:              Y = majority(A, B, C)
#   HA            Half Adder:            SUM = A^B, COUT = A&B   [only size: xp5 — cannot sizeup]
#   FA            Full Adder:            SUM, COUT from A, B, CIN [only size: x1 — cannot sizeup]
#   DFFHQN        D flip-flop, inverted output, high-speed        [do not resize]
#   DFFLQN        D flip-flop, inverted output, low-power         [do not resize]
#   DFFHQ         D flip-flop, true output, high-speed            [do not resize]
#   ICG           Integrated Clock Gate                           [clock network — do not touch]
#   CKINVDC       Clock inverter, DC-balanced                     [clock network — do not touch]
#
# CONSTRAINTS
#   - Never resize, buffer, or clone clock network cells (CKINVDC, ICG, clkbuf_* instances)
#   - HA and FA have only one size; fix their paths by buffering their output or cloning upstream drivers
#   - A critical-path cell with high output capacitance is a candidate for sizeup or output buffering
#   - A critical-path cell with fanout > 4 is a candidate for clone or split
# ============================================================
